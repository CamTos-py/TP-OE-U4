# TP-OE-U4 - Análisis de Ventas

## Integrante
- Camila Soledad Tosti (Roles: Hugo P1, Paco P2, Luis P3)

## Escenario elegido
Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción del dataset
Utilización del dataset simulado de ventas comerciales con registros de producto,
cantidad vendida, precio unitario y fecha de venta brindado por la cátedra.
Almacenado en: datos/ventas.csv

## Indicadores calculados
- Ventas totales
- Producto más vendido
- Ventas por mes

## Instrucciones para ejecutar el script
1. Clonar el repositorio:
   git clone https://github.com/CamTos-py/TP-OE-U4.git

2. Abrir Google Colab y subir el repositorio clonado

3. Ejecutar el script:
   exec(open("scripts/analisis_ventas.py").read())

4. Los resultados se guardan automáticamente en /resultados

## Estructura del repositorio
- /datos → dataset de ventas en formato CSV
- /scripts → script de análisis en Python
- /resultados → gráfico generado por el análisis
- README.md → documentación del proyecto
- .gitignore → archivos excluidos del repositorio
